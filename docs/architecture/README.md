# Arquitectura

```
RadhikaChain L1
├── dharma-gate-core (minero + consenso)
├── prana-engine (ledger + pagos)
├── samsara-core (optimizer + ZK)
├── tesseract-hunt (detección de amenazas)
├── tattva-swarm (orquestación)
└── hermes-kanban (gestión de tareas)
```
